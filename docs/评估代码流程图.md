## 关键数据结构

### 输入数据 (batch)
```python
batch = {
    "image_front": Tensor[B, H, W, C],          # 前视图像
    "image_front_time": Tensor[B, H, W, C],     # 前视历史图像
    "image_back": Tensor[B, H, W, C],           # 后视图像（可选）

    "language_instruction": List[str],          # 语言指令

```

### 模型输入
```python
inputs = {
    "input_ids": Tensor[B, seq_len],            # 文本token ids

```

## Flow Matching采样详解

Flow Matching是用于生成动作轨迹的扩散式方法：

1. **初始化**：从标准高斯分布采样 `action_0 ~ N(0, I)`
2. **迭代去噪**：从 t=0 到 t=1，共 `num_inference_steps` 步
   - 时间步：`t = step * delta_t`，其中 `delta_t = 1.0 / num_inference_steps`
   - 编码时间条件：`time_cond = time_embedding(t)`
   - 编码当前动作：`action_embeds = action_encoder(action, time_cond)`
   - 通过联合模型（使用VLM和Proprio的KV缓存）：`action_embeds = joint_model(...)`
   - 解码动作速度：`action_vel = action_decoder(action_embeds)`
   - Euler更新：`action = action + delta_t * action_vel`
3. **最终裁剪**：`action = clamp(action, -clip_value, clip_value)`

## 评估指标计算

### 动作准确率
对每个阈值 `threshold`：
1. 计算绝对误差：`diff = |gt - pred|`，形状为 `[B*horizon, action_dim]`
2. 对每个时间步，检查所有动作维度是否都小于阈值
3. 计算准确率：`accuracy = mean((mean(diff < threshold, dim=1) >= 1.0))`

### L1/L2损失
1. 将预测和真实轨迹反归一化到原始坐标空间
2. 计算平均绝对误差（L1）或均方误差（L2）
